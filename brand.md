## Typography — Inter + JetBrains Mono

- **Display and body:** Inter
- **Mono (numbers, filenames, page counts, costs):** JetBrains Mono
- **Fallbacks:** use the existing local system stacks when web fonts are unavailable.

CSS variables: `--font-sans` and `--font-mono`. The comparison viewer remains self-contained and must not depend on runtime font requests.

### Type scale

| Role | Size / weight | Use |
|---|---|---|

## Gradients

Two restrained gradients are available. The workspace should normally use only the background gradient; reserve the accent gradient for a small decorative mark or non-text accent.

**Light mode:**

```css
--gradient-bg: linear-gradient(135deg, oklch(0.97 0.008 145) 0%, oklch(0.94 0.013 160) 100%);
--gradient-accent: linear-gradient(to right, oklch(0.50 0.17 40) 0%, oklch(0.52 0.18 70) 100%);
```

**Dark mode:**

```css
--gradient-bg: linear-gradient(135deg, oklch(0.14 0.008 145) 0%, oklch(0.17 0.013 160) 100%);
--gradient-accent: linear-gradient(to right, oklch(0.72 0.17 40) 0%, oklch(0.74 0.18 70) 100%);
```

Do not place body text directly on the accent gradient, animate either gradient, or use both gradients prominently on one screen.

## Tone and voice

### Words to use

Use sparse, specific, active language. Name the document, output, stage, percentage, page count, and recovery action. Prefer “Convert PDF,” “Processing page 17 of 24,” and “Try again.”

### Words to avoid

Avoid hype and effort claims: “revolutionary,” “powerful,” “seamless,” “simply,” “just,” and “easy.” Avoid vague failures, exclamation marks, and unsupported privacy promises.

### Voice example

> 24 pages. DOCX selected. Your source is deleted from Mathpix after local outputs are stored.

## Usage dos and don'ts

**Do:**

- Use semantic CSS variables for every interface color.
- Keep the 4 px spacing grid and a consistent 8 px control radius.
- Keep coral for primary actions and selected states.
- Use mono tabular numbers for progress, sizes, page counts, and cost.
- Test light and dark modes at 375 px, 768 px, and 1280 px.

**Don't:**

- Hardcode colors in components when a semantic token exists.
- Use `transition: all`; name the specific property.
- Mix multiple accent colors without semantic meaning.
- Place body text on the accent gradient.
- use tiny low-contrast metadata to make the interface look “clean.”
